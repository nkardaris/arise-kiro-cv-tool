# examples/

Assets for running `cv_tool` without the original industrial hardware.

The recorded rosbag is an **external download** — see
[`docs/04_basic_demo_how_to_use.md`](../../../../../docs/04_basic_demo_how_to_use.md) for the
download link, bag details, and full demo walkthrough. Run it with:

```bash
ros2 launch cv_tool cv_tool_demo.launch.py bag_path:=/cv_tool_ws/rosbags/boxes_0.db3
```
